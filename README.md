# 音流独立音频接收器 v1.1.18

播放会自动展开歌词。缩回预览后，顶部工具栏始终提供“全屏歌词”；底部“调谐”调整风格、时间与速度，“水波”独立开关。后台与系统页包含防杀和固化入口，固化后需重启。

接收台的「妙播音频延时」滑块按 5 ms 调整，范围为 −400 至 +400 ms。正值延后，负值提前，归零使用发送端时钟自动排程。设置由接收服务保存，播放中松手生效。Pad 6 的 AAudio 输出缓冲实测为 50 ms（48 kHz 下 2,400 帧）。

完整歌词仅来自导入 LRC、发送端内嵌 LRC 或开启联网后的匹配结果。LAN 自动记录存为 `.fragment`，不自动用作完整时间轴；旧 `_lanrec.lrc` 首次启动迁移为片段，已有导入和联网缓存保留。DLNA 使用播放器实际进度，不用旁路逐句歌词重置时间；曲长修正不触发换歌。同一歌曲的重复完整歌词载荷不重建视图。

同机只能开启一个占用 `8899/55982` 的 MiPlay 接收器。另一项目 `cn.padreceiver.audio` 的源码、APK、模块均独立保留，本次未修改。

DLNA 的音频频谱分析为可选能力：Android 的 Visualizer 要求录音权限，但实现只附着本应用播放会话，没有 AudioRecord/MediaRecorder，不打开麦克风。未授权时 DLNA 正常播音和显示歌词；小米投送频谱直接取解码 PCM，不需该权限。

验证入口集中在 `../../调试文件/音流独立接收器/`：`browser_verify.mjs`、`device_verify.py`、`preview_verify.py`、`LyricRegression.java` 与 `run_host_regression.py`。主机歌词回归运行原始 LyricOrchestrator 源码，Android 调度/时钟/视图以最小 stub 替代。浏览器测试所需临时 Playwright/Chromium 已按 SOP 清理，重跑时在该调试目录的 browser-check 下安装 playwright 及 Chromium。Android 真机脚本只使用本地生成的测试音频和歌词，结束后恢复旋转及亮屏设置、删除测试缓存与 ADB 映射。
